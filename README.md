# Community Links Pack — Free FiveM Resource

Give your players one-tap access to your community links, right in chat.
**Standalone** — no framework, no database, 2-minute setup.

## Commands

- `/discord` — posts your Discord invite
- `/store` — posts your store link
- `/website` — posts your website link
- `/rules` — posts your server rules
- `/help` — lists the commands with your server name

Every command appears in the chat suggestion box, carries a built-in
anti-spam cooldown, and is styled with your accent color.

## Installation

1. Drop the `community-links-pack` folder into your server's `resources` folder
2. Add `ensure community-links-pack` to your `server.cfg`
3. Edit `config.lua` — server name, links, rules, cooldown, accent color
4. Restart the server (or `refresh` + `start community-links-pack`)

Hide any link command by leaving its link blank (`''`) in the config.
